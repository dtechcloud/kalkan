Nasıl çalışırHow it works

Şüpheden kanıta.From candidates to quoted proof.

Araçlar şüphelileri bulur. Ajanlar paralel çalışır ve her iddiayı kaynaktan alıntılar. Motor alıntıları dosyada arar, kararı o verir. Kanıtı ağsız bir sandbox'ta sınar.

The tools find the candidates. Agents work in parallel and quote the source for every claim. The engine looks up each quote in the file and makes the verdict. A PoC tests the proof in a sandbox without network.

  1. 01

    TaraScan

    22 sabit sürümlü araç ve yerel SCA paralel çalışır. Ağ kullanmazlar.22 pinned tools and local SCA run in parallel, without network.

    opengreptrivygitleakscheckovosvgrypebanditgoseczizmor+13

    → şüpheliler · SARIF→ candidates · SARIF

  2. 02

    AraHunt

    Avcı ajanlar kapsam birimlerini paralel tarar. Eleştirmen boşlukları bulur, yeni dalga açar.Hunter agents cover the coverage units in parallel. A critic finds the gaps and opens a new wave.

    hunter·1 hunter·2 hunter·3 hunter·4 hunter·5 critic

    → iz taşıyan iddialar→ claims with a trace

  3. 03

    DoğrulaVerify

    Doğrulayıcı üç soruyu alıntıyla cevaplar. Motor her alıntıyı dosyada arar. Taze gözlü bir ajan son kez inceler.A verifier answers three questions with quotes. The engine finds each quote in the file. A fresh-eyes agent reviews it once more.

    ✓saldırgan ulaşır mı?attacker control ✓yetki sınırı aşılır mı?privilege boundary ✓önlem yok mu?unmitigated ✗alıntı dosyada yokquote not in file

    → doğrulandı · doğrulama bekliyor · reddedildi→ confirmed · needs validation · rejected

  4. 04

    KanıtlaProve

    Bir ajan küçük bir PoC yazar. Motor onu Docker'da ağsız ve salt okunur bir konteynerde çalıştırır.An agent writes a small PoC. The engine runs it in Docker, in a read-only container without network.

    sandbox --network none--read-only--cap-drop ALLuid 65534 · 180 s ✓ etki gösterildieffect shown

    → çalışma zamanı kanıtı→ runtime evidence

  5. 05

    RaporlaReport

    Aynı kök nedenli kayıtlar birleşir. Yönetici özeti ve makine okuyabilir çıktılar yazılır.Records of one root cause fold into one. An executive summary and machine-readable files follow.

    EXECUTIVE.htmlREPORT.mdfindings.sarifsbom.cdx.json

    → her bulgu kaynağını alıntılar→ every finding quotes its source

Motor dil modeli çağırmaz: durumu diskte tutar, şemaları ve alıntıları kontrol eder, kararı verir. Kullanım limiti dolarsa denetim bekler ve kaldığı yerden devam eder.The engine never calls a language model: it keeps the state on disk, checks the schemas and the quotes, and makes the verdict. A usage limit only pauses the audit; it continues where it stopped.

Neden kalkanWhy kalkan

Gürültü değil, kanıt.Proof, not noise.

Güvenlik tarayıcıları çok sayıda şüpheli üretir. Dil modeli incelemeleri ise ikna edici ama kimsenin kontrol etmediği iddialar yazabilir. kalkan ikisini birleştirir ve her iddiayı kaynağa bağlar.

Security scanners produce many candidates. LLM reviews can write convincing claims that nobody checked. kalkan combines both and ties every claim to the source.

Sorun · tarayıcı gürültüsüProblem · scanner noise

Doğrulanmamış sonuç bulgu sayılmaz.An unverified result is not a finding.

OWASP Juice Shop'ta yalnız araçlar 1200 şüpheli üretti. kalkan bir araç sonucunu ajanlar kodda izleyip doğrulamadan bulgu saymaz. Doğrulanmayanlar raporda ayrı bir listede kalır.

On OWASP Juice Shop, the tools alone gave 1,200 candidates. kalkan counts a tool result as a finding only after the agents trace and verify it in the code. The unverified ones stay in a separate list of the report.

Sorun · uydurma iddiaProblem · made-up claims

Her iddia bir alıntı taşır.Every claim carries a quote.

Doğrulayıcı ajan her yanıtının arkasındaki kodu alıntılar. Motor her alıntıyı dosyada arar (±2 satır). Dosyada olmayan bir alıntı kanıt sayılmaz.

The verifier agent quotes the code behind each answer. The engine looks up every quote in the file (±2 lines). A quote that is not in the file counts as no evidence.

Sorun · yarıda kalan denetimProblem · audits that stop halfway

Limit dolsa da kaldığı yerden devam eder.A usage limit is only a pause.

Denetimin bütün durumu diskte durur. Kullanım limiti dolarsa kalkan sıfırlanmayı bekler ve kaldığı yerden devam eder. Hiçbir görev kaybolmaz, hiçbiri iki kez çalışmaz.

All audit state lives on disk. When a usage limit stops the audit, kalkan waits for the reset and continues where it stopped. No task is lost, and none runs twice.
