14

kalkan bilgisayarıma ne kurar?What does kalkan install on my computer?

Kurulum yedi parça ekler. Hepsi senin kullanıcı klasöründe durur. kalkan yönetici hakkı istemez.

The setup adds seven parts. All of them stay in your user folder. kalkan needs no administrator rights.

  • Plugin/kalkan skill'i, 10 ajan, bir PreToolUse hook'u ve motorun wheel dosyası. Claude Code bunları plugin klasörüne kopyalar.The /kalkan skill, 10 agents, a PreToolUse hook and the wheel file of the engine. Claude Code copies them into the plugin folder.
  • Marketplacekalkan reposunun Claude Code'daki kopyası. Claude Code plugin'i ve güncellemelerini buradan okur.The copy of the kalkan repository in Claude Code. Claude Code reads the plugin and its updates from it.
  • MotorEngineBir Python venv'i ve içinde kalkan motoru. Motor bir karar vermek için hiçbir dil modelini çağırmaz.A Python venv with the kalkan engine in it. The engine makes no model call to decide a verdict.
  • TarayıcılarScanners21 sabit sürümlü tarayıcı. Go araç zinciriyle birlikte 22 araç. Kurulum, indirilen 15 programı ve Go araç zincirini sabit bir SHA-256 değeriyle kontrol eder. pip, 4 Python aracını tam sürümüyle kurar, hash kontrolü yapmaz. Go checksum veritabanı, go install ile derlenen 2 aracı kontrol eder. Liste: Araçlar.21 pinned scanners, 22 tools with the Go toolchain. Setup checks the 15 downloaded programs and the Go toolchain against a pinned SHA-256. pip installs the 4 Python tools by exact version, without a hash check. The Go checksum database checks the 2 tools that go install builds. The list: Tools.
  • Go araç zinciriGo toolchainGo 1.26.9. gosec ve govulncheck onunla çalışır. kalkan iki Go aracını onunla derler. Senin Go kurman gerekmez.Go 1.26.9. gosec and govulncheck run with it. kalkan builds two Go tools with it. You do not need to install Go.
  • Zafiyet veritabanlarıVulnerability databasesGrype, OSV (13 ekosistem), Go ve RetireJS. SCA bunları ağsız kullanır.Grype, OSV (13 ecosystems), Go and RetireJS. SCA uses them without network.
  • BaşlatıcılarLauncherskalkan-audit ve kalkan-unattended, Windows için .cmd dosyalarıyla. Plugin güncellense de yolları aynı kalır.kalkan-audit and kalkan-unattended, with .cmd files for Windows. Their paths stay the same after a plugin update.

İlk denetimde kalkan opengrep çalışma ortamını .tools/cache/opengrep klasörüne açar (289,8 MB). Bütün parçalar birlikte yaklaşık 5,5 GB tutar. Plugin klasörü yaklaşık 3 MB, marketplace kopyası 27 MB tutar. Bu boyutlar bir Windows 11 makinesinde bir kez ölçüldü. Parçaların boyutu: Disk kullanımı.

On the first audit, kalkan unpacks the opengrep runtime into .tools/cache/opengrep (289.8 MB). All parts together use about 5.5 GB. The plugin folder uses about 3 MB, and the marketplace copy uses 27 MB. These sizes were measured once on one Windows 11 machine. The size of each part: Disk usage.

Ne kurmaz?What it does not install

  • Sistem paketi kurmaz ve PATH'i değiştirmez.It installs no system package and does not change PATH.
  • Servis veya arka planda çalışan bir işlem kurmaz.It installs no service and no background process.
  • Kendiliğinden Docker imajı indirmez. PoC sandbox imajlarını sen kalkan sandbox pull ile indirirsin. İsteğe bağlı --allow-build-network ile denetim, hedefin compose yığınının imajlarını da çeker ve derler.It pulls no Docker image on its own. You pull the PoC sandbox images with kalkan sandbox pull. With the opt-in --allow-build-network, an audit also pulls and builds the images of the target's compose stack.
  • Python, git ve Claude Code kurmaz. Bunlar gereksinimdir.It does not install Python, git or Claude Code. These are requirements.

15

Nereye kurar?Where does it install it?

kalkan dört klasör kullanır. Hepsi senin kullanıcı klasöründedir. Aşağıda ~ senin kullanıcı klasörün demektir.

kalkan uses four folders. All of them are in your user folder. Below, ~ means your user folder.

  • ~/.claude/plugins/data/kalkan-kalkan/Veri klasörü. Motor (venv/), tarayıcılar, Go, veritabanları ve önbellekler (.tools/), başlatıcılar (bin/) ve hook durumu (hook/). Kaldırma bu klasörü siler, --keep-data ile tutar.Data folder. The engine (venv/), the scanners, Go, the databases and the caches (.tools/), the launchers (bin/) and the hook state (hook/). The uninstall deletes this folder, unless you add --keep-data.
  • ~/.claude/plugins/cache/kalkan/kalkan/<version>/Plugin klasörü. Skill, ajanlar, hook ve motorun wheel dosyası. Her plugin sürümünün kendi klasörü vardır.Plugin folder. The skill, the agents, the hook and the wheel file of the engine. Each plugin version has its own folder.
  • ~/.claude/plugins/marketplaces/kalkan/Marketplace kopyası. Claude Code'un kalkan reposundan aldığı kopya.Marketplace copy. The copy of the kalkan repository that Claude Code keeps.
  • ~/kalkan-runs/Denetimler klasörü. Her denetimin klasörü ve raporu. Kaldırma bu klasörü tutar.Runs folder. The folder and the report of each audit. The uninstall keeps this folder.

  • LinuxVeri klasörü: /home/<user>/.claude/plugins/data/kalkan-kalkan
    Denetimler klasörü: /home/<user>/kalkan-runs    Data folder: /home/<user>/.claude/plugins/data/kalkan-kalkan
    Runs folder: /home/<user>/kalkan-runs

Plugin klasörü ve marketplace kopyası, veri klasörünün yanında .claude/plugins/ altındadır. Motor, veri klasöründe Windows'ta venv\Scripts\kalkan.exe, Linux ve macOS'ta venv/bin/kalkan dosyasıdır. Veri klasöründeki venv/kalkan-home.json dosyası, motorun veri klasörünü ve denetimler klasörünü yazar.

The plugin folder and the marketplace copy are next to the data folder, below .claude/plugins/. The engine is the file venv\Scripts\kalkan.exe of the data folder on Windows, and venv/bin/kalkan on Linux and macOS. The file venv/kalkan-home.json in the data folder names the data folder and the runs folder of the engine.

Yerleri değiştirChange the places

  • KALKAN_RUNS_DIRDenetimler klasörünü taşır. Değişkeni Claude Code'u başlatan ortamda ayarla. Klasör denetlenen projenin dışında olmalı. Windows'ta C:\kr gibi kısa bir yol, uzun yol sınırını da önler.Moves the runs folder. Set the variable in the environment that starts Claude Code. The folder must be outside the audited project. On Windows, a short path such as C:\kr also avoids the long path limit.
  • CLAUDE_CONFIG_DIRBütün ~/.claude klasörünü taşır, plugins/ dahil. Bu değişken ayarlıysa plugin klasörleri o klasördedir.Moves the whole ~/.claude folder, plugins/ included. When this variable is set, the plugin folders are in that folder.
  • CLAUDE_CODE_PLUGIN_CACHE_DIRClaude Code'un plugin kök klasörünü (~/.claude/plugins) değiştirir.Replaces the plugins root of Claude Code (~/.claude/plugins).

Repoyu klonlayıp bootstrap betiğiyle kurduysan kalkan .venv, .tools ve runs klasörlerini checkout'un içinde tutar.If you cloned the repository and used the bootstrap script, kalkan keeps .venv, .tools and runs in the checkout folder.

16

Makinede neyi değiştirir?What it changes on the machine

kalkan sistem ayarlarına dokunmaz. Her araç dosyalarını kalkan klasörlerinde tutar. opengrep çalışma ortamı .tools/cache/opengrep içinde durur. Günlükler, geçici dosyalar, Go derleme önbelleği ve telemetrisi kapalı Go ayarları denetimin iş klasöründe durur. pip indirme önbelleği kullanmaz.

kalkan does not touch the system settings. Every tool keeps its files inside the kalkan folders. The opengrep runtime is in .tools/cache/opengrep. The logs, the temporary files, the Go build cache and the Go settings with telemetry off are in the work folder of the run. pip uses no download cache.

Ölçüm (29 Ekim 2026, Windows 11): 22 aracın hepsiyle 2.307 dosyalık bir reponun yalnızca araç denetimi. Bu denetimde kalkan klasörleri dışında yalnız başka programların kendi dosyaları değişti. Linux ve macOS'ta bu ölçümü yapmadık. macOS'ta Go telemetrisi senin kendi Go ayarına uyar.

Measurement (29 October 2026, Windows 11): a tools-only audit of a repository with 2,307 files, with all 22 tools. In this audit, only the own files of other programs changed outside the kalkan folders. We did not measure this on Linux or macOS. On macOS, Go telemetry follows your own Go setting.

  • Yönetici hakkı istemez.It needs no administrator rights.
  • PATH'i değiştirmez. Komutları tam yollarıyla çalıştırırsın: bkz. Komutlar ve yollar.It does not change PATH. You run the commands with their full paths: see Commands and paths.
  • Sistem paketi kurmaz. Python araçları kendi venv'lerinde, Go kendi klasöründe durur.It installs no system package. The Python tools stay in their own venvs, and Go stays in its own folder.
  • Denetlenen projede hiçbir dosyayı değiştirmez.It changes no file of the audited project.

Claude Code'da ne değişir?What changes in Claude Code?

Kurulum, Claude Code'a kalkan marketplace'ini ekler. Plugin'i senin kullanıcın için kurar (user scope). Plugin her klasörde çalışır.

The setup adds the kalkan marketplace to Claude Code. It installs the plugin for your user (user scope). The plugin works in every folder.

Plugin, Claude Code'a bir PreToolUse hook'u ekler. Hook, kalkan ajanlarını kendi denetim klasörlerinde tutar. Bir ajan, aynı oturumun büyük araç çıktılarını da okuyabilir. Claude Code bu çıktıları dosyaya kaydeder. Bir oturum denetim yürütürken hook o oturumun ağ araçlarını engeller. Diğer oturumlarında hiçbir çağrıyı reddetmez.

The plugin adds a PreToolUse hook to Claude Code. The hook keeps the kalkan agents in their own run folders. An agent can also read the large tool outputs of the same session, which Claude Code saves to files. While a session runs an audit, the hook blocks the network tools of that session. It never denies a call in your other sessions.

Hook yalnız bazı çağrılarda başlar. Bu çağrılar Read, Grep, Glob, Write, NotebookEdit, web ve MCP araçları, kalkan veya bir ağ kelimesi içeren Bash komutları ve bir ağ kelimesi içeren PowerShell komutlarıdır. Windows'ta ilgisiz bir çağrıya yaklaşık 0,2 saniye ekler (bir Windows 11 makinesinde bir kez ölçüldü). Ayrıntılar: Güvenlik.

The hook starts only for some calls. These calls are Read, Grep, Glob, Write, NotebookEdit, the web and MCP tools, Bash commands that contain kalkan or a network word, and PowerShell commands that contain a network word. On Windows, the hook adds about 0.2 seconds to an unrelated call (measured once on one Windows 11 machine). Details: Security.

Kullanımı görSee the usage

Bayraksız kalkan clean hiçbir şey silmez. Komut her parçanın boyutunu, dosya sayısını ve klasörünü yazar: motor, araçlar, veritabanları, önbellekler, denetimler ve toplam. kalkan doctor bilgi satırı footprint içinde araçların, veritabanlarının, önbelleklerin ve denetimlerin boyutunu ve toplamını gösterir. claude plugin list --json --data-size plugin veri klasörünün boyutunu verir (Claude Code 2.1.285 veya sonrası).

Without a flag, kalkan clean deletes nothing. The command prints the size, the file count and the folder of each part: the engine, the tools, the databases, the caches, the runs and the total. In its info row footprint, kalkan doctor shows the size of the tools, the databases, the caches and the runs, and their total. claude plugin list --json --data-size gives the size of the plugin data folder (Claude Code 2.1.285 or later).

Yer açFree space

Denetimler zamanla birikir. Kaldırma onları silmez.

The runs add up over time. The uninstall does not delete them.

Dikkat: Bir denetim klasörünü silmeden önce saklamak istediğin raporları kopyala. Silinen veritabanlarını ve araçları sonraki denetim yeniden ister.

Caution: Copy the reports that you want to keep before you delete a run folder. The next audit needs the deleted databases and tools again.

  • kalkan run clean <run-id>Bitmiş bir denetimin target/ (kod kopyası), source/ (geçmiş kopyası), scans/.work/ ve sca/.work/ klasörlerini siler. report/, durum dosyası ve araç ile görev sonuçları kalır. Temizlenen bir denetim devam edemez, ama kalkan run status çalışır. Bitmemiş bir denetimi yalnız --force ile temizler.Deletes target/ (the code copy), source/ (the history copy), scans/.work/ and sca/.work/ of a finished run. report/, the state and the tool and task results stay. A cleaned run cannot resume, but kalkan run status still works. The command cleans an unfinished run only with --force.
  • kalkan clean --runs · --caches · --databases · --tools · --allBir bayrakla kalkan clean o parçayı siler: denetimleri, önbellekleri, veritabanlarını, araçları veya motor dışında hepsini. --keep-reports, --runs veya --all ile her denetimin report/ klasörünü tutar.With a flag, kalkan clean deletes that part: the runs, the caches, the databases, the tools, or everything except the engine. --keep-reports with --runs or --all keeps the report/ folder of every run.
  • --dry-run · -yKomut önce silinecekleri ve toplam boyutu listeler, sonra y/N sorar. --dry-run yalnız listeyi gösterir. -y (--yes) soruyu atlar. Terminal yoksa komut -y olmadan hiçbir şey silmez.The command first lists what it will delete and the total size, then asks y/N. --dry-run shows only the list. -y (--yes) skips the question. Without a terminal, the command deletes nothing unless you add -y.

kalkan clean kendisini çalıştıran motoru ve bir checkout'un kaynak dosyalarını asla silmez. kalkan işareti olmayan bir klasörde silmeyi reddeder. Bağlantıları ve Windows junction'larını bağlantı olarak siler, gösterdikleri klasöre dokunmaz.

kalkan clean never deletes the engine that runs it or the source files of a checkout. It refuses to delete in a folder without a kalkan marker. It removes links and Windows junctions as links, and the folders that they point to stay.

kalkan'ı tamamen kaldırmak için: Tam temizlik.

GizlilikPrivacy

Denetim sırasında makineden yalnız kendi Claude oturumunun trafiği çıkar: Anthropic'e veya API sağlayıcına gider. kalkan bu trafiğe bir şey eklemez. Hedef bir git URL'si ise kalkan onu önce klonlar. --online ve --allow-build-network gibi isteğe bağlı bayraklar ek trafik açar: bkz. Ağ davranışı.

During an audit, only the traffic of your own Claude session leaves the machine, to Anthropic or to your API provider. kalkan adds nothing to this traffic. A git URL target is cloned first. Opt-in flags such as --online and --allow-build-network add more traffic: see Network behavior.

  • KodunYour codeAjanlar kodu senin Claude Code oturumunda okur. Claude Code okuduğu dosyaları Anthropic'e veya API sağlayıcına gönderir. Claude Code'un kendi telemetrisi senin Claude Code ayarlarına uyar.The agents read the code in your Claude Code session. Claude Code sends the files that it reads to Anthropic or to your API provider. The telemetry of Claude Code follows your Claude Code settings.
  • TarayıcılarScannersTarayıcılar ve SCA ağsız çalışır. kalkan araçların telemetrisini ve güncelleme kontrollerini kapatır.The scanners and SCA run without network. kalkan disables the telemetry and the update checks of the tools.
  • Paket adlarıPackage namesSCA yerel veritabanlarını kullanır. Paket adların ve sürümlerin yalnız isteğe bağlı --online seçeneğiyle dışarı çıkar.SCA uses local databases. Your package names and versions leave the machine only with the opt-in --online flag.
  • SırlarSecretsGitleaks ve Kingfisher buldukları değerleri gizler. Hiçbir sır değeri bir kalkan dosyasına ulaşmaz. Kingfisher bir sırrı sağlayıcısında asla denemez.Gitleaks and Kingfisher redact the values that they find. No secret value reaches a kalkan file. Kingfisher never tries a secret at its provider.
  • RaporlarReportsRaporlar kanıt olarak kodundan satırlar alıntılar. Bir raporu kodun kendisi kadar dikkatli paylaş.The reports quote lines of your code as evidence. Share a report as carefully as the code.
  • Denetim klasörüRun folderKodun bir kopyasını ve bütün git geçmişini tutar. Geçmişte silinmiş bir sır da oradadır. Denetim bitince bu klasörü koru. kalkan run clean <run-id> kod kopyasını ve geçmiş kopyasını siler, raporu tutar.It holds a copy of the code and the full git history. A secret that a commit deleted is still there. When the audit is done, protect this folder. kalkan run clean <run-id> deletes the code copy and the history copy, and keeps the report.

kalkan'ın ağı ne zaman kullandığı: Ağ davranışı. Taahhütler ve testler: Güvenlik modeli.

When kalkan uses the network: Network behavior. The commitments and the tests: Security model.

19

Ağ davranışıNetwork behavior

İsteğe bağlı bayraklar olmadan tarayıcılar, SCA ve motor denetim sırasında ağ kullanmaz. Ağı yalnız aşağıdaki işler kullanır. Her birini sen başlatırsın.

Without the opt-in flags, the scanners, SCA and the engine use no network during an audit. Only the jobs below use the network. You start each of them yourself.

  • Kurulum betiğiThe installerHedef: github.com. Giden veri: kalkan reposu için git istekleri.Destination: github.com. Data sent: git requests for the kalkan repository.

Giden veri: yalnız sabit araç adları ve sürümleri.Destination: GitHub releases, PyPI, get.helm.sh, go.dev and the Go module proxy. Giden veri: yalnız ekosistem adları ve arşiv istekleri.Destination: osv-vulnerabilities.storage.googleapis.com, grype.anchore.io, vuln.go.dev, raw.githubusercontent.com. The setup, kalkan sca update-db and --yes download the databases from these hosts. Data sent: only ecosystem names and archive requests.

Bir oturum denetim yürütürken plugin hook'u o oturumun ağ araçlarını engeller: WebFetch, WebSearch, MCP araçları ve ağ komutları. Engel, denetim bitince veya son motor komutundan 6 saat sonra kalkar. Hook diğer oturumlarına dokunmaz.

While a session runs an audit, the plugin hook blocks the network tools of that session: WebFetch, WebSearch, the MCP tools and network commands. The block ends when the audit is done, or 6 hours after the last engine command. The hook does not touch your other sessions.

Eksik bir veritabanı çevrimiçi bir sorguya dönüşmez. sca match bir veritabanı boşluğu kaydeder ve rapor bu boşluğu gösterir. Kurulum tamamsa, yerel bir klasörün --tools-only denetimi hiç ağ kullanmaz.

A missing database never becomes an online query. sca match records a database gap, and the report shows the gap. When the setup is complete, a --tools-only audit of a local folder uses no network at all.

Test: araçlar, bağlantıları sayan bir tuzak proxy ile çalıştı. Yerel modda sıfır bağlantı açtılar. Ayrıntılar: Güvenlik.

Test: the tools ran with a trap proxy that counts the connections. In local mode, they opened zero connections. Details: Security.

Güvenlik modeliSecurity model

kalkan güvenmediğin kodu denetler. Bu yüzden güvenlik konusunda üç taahhüt verir. Her taahhüdü bir test korur.

kalkan audits code that you do not trust. Thus it makes three security commitments, and a test backs each one.

  1. 01Denetlenen proje değişmez. Denetim bir kopya üzerinde çalışır. Tuzaklı bir repo testi her dosyayı, klasörü ve değişiklik zamanını kontrol eder.The audited project never changes. The audit works on a copy. A trap repository test checks every file, folder and modification time.
  2. 02Ajanlar yalnız kendi sonuç dosyasına yazar. Alt ajanların yalnız Read, Grep, Glob ve Write araçları var. Kabuk, web ve MCP aracı yok. Plugin hook'u onları kendi denetim klasörlerinde tutar.Agents write only their own result file. The subagents have only Read, Grep, Glob and Write. They have no shell, no web and no MCP tools. The plugin hook keeps them in their own run folders.
  3. 03Veri makinede kalır. Kendi Claude oturumunun Anthropic'e veya API sağlayıcına giden trafiği dışında hiçbir veri makineden çıkmaz. Hedef bir git URL'si ise kalkan onu önce klonlar. İsteğe bağlı --allow-build-network, PoC sandbox'ının hedefin compose yığınının imajlarını ağ erişimiyle çekmesine ve derlemesine izin verir. Proxy tuzağı testinde gerçek araçlar sıfır bağlantı açtı.Data stays on the machine. No data leaves the machine, except the traffic of your own Claude session, to Anthropic or to your API provider. A git URL target is cloned first. The opt-in --allow-build-network lets the PoC sandbox pull and build the images of the target's compose stack with network access. In the proxy trap test, the real tools opened zero connections.

Tarayıcılar hedef kodu asla çalıştırmaz. Docker varsa PoC sandbox hedef kodu yalnız kopyadan, ağsız bir konteynerde çalıştırır. Hedefin ajan talimat dosyaları etkisiz kalır. Her ajan istemi, hedefin talimat değil veri olduğunu söyler.

The scanners never run target code. With Docker, the PoC sandbox runs target code only from the copy, in a container without network. The agent instruction files of the target have no effect. Every agent prompt says that the target is data, not instructions.

Kalan riskler de yazılıdır. Örneğin plugin modunda ana oturum senin izin moduna uyar. Ağ komutu listesi bir sezgiseldir. Ayrıntılar ve testler: Güvenlik sayfası ve docs/SECURITY.md.

The residual risks are written down too. For example, in plugin mode the main session follows your permission mode. The list of network commands is a heuristic. Details and tests: the Security page and docs/SECURITY.md.

Neden her şey Docker'da değil?Why not everything in Docker?

Tarayıcıları kullanıcılar için bir Docker imajına taşımıyoruz. Bu kararı 29 Ekim 2026'da verdik. Dört nedeni var:

We do not move the scanners into a Docker image for users. We made this decision on 29 October 2026. There are four reasons:

  1. 01Disk kazancı yok. Zafiyet veritabanları (3,67 GB) iki yolda da gerekir. Docker yolu ayrıca yaklaşık 2 GB'lık bir imaj ve Docker Desktop'ın kendi disk dosyasını ister.It saves no disk. Both ways need the vulnerability databases (3.67 GB). The Docker way also needs an image of about 2 GB and the own disk file of Docker Desktop.
  2. 02Kaldırma zaten tek komut. claude plugin uninstall kalkan@kalkan veri klasörünü siler.The uninstall is already one command. claude plugin uninstall kalkan@kalkan deletes the data folder.
  3. 03Ajanlar ana makinede çalışır. Claude Code ajanları dosyaları ana makinedeki yollarla okur. Tarayıcılar konteynerde olsaydı, kalkan her yolu ana makine ile konteyner arasında çevirmek zorunda kalırdı. Bu çeviri 2-3 günlük iş ister. Ayrıca bakımı gereken ikinci bir çalışma yolu ekler.The agents run on the host. The Claude Code agents read the files through host paths. If the scanners ran in a container, kalkan would have to translate every path between the host and the container. This translation is 2 to 3 days of work. It also adds a second execution path to maintain.
  4. 04Windows'ta ek yük. Docker Desktop, WSL2 ve yönetici hakkıyla bir kurulum ister. Linux konteynerlerine bağlanan Windows klasörleri daha yavaş çalışır.Extra cost on Windows. Docker Desktop needs WSL2 and an install with administrator rights. Windows folders that you mount into Linux containers are slower.

Docker'ın kalkan'da tek bir görevi var: PoC sandbox. Sandbox küçük çalışma zamanı imajları kullanır.

Docker has one job in kalkan: the PoC sandbox. The sandbox uses small runtime images.

Repodaki docker/ klasörü, CI pipeline'ları için bir imaj tutar. Bu imaj desteklenen bir kurulum yolu değil. İmaj güncel araç seti için derlenmedi.The docker/ folder of the repository holds an image for CI pipelines. This image is not a supported install path. It was not built for the current tool set.
