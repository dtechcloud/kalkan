Sık sorulanlarFAQ

Kısa cevaplar.Short answers.

Kodum makineden çıkıyor mu?
Tarayıcılar ve SCA çevrimdışı çalışır. Ajanlar senin Claude Code oturumunda çalışır ve Claude Code okuduğu dosyaları Anthropic'e veya API sağlayıcına gönderir. Bu senin kendi Claude trafiğin. kalkan ona bir şey eklemez. Hedef bir git URL'si ise kalkan onu önce klonlar. İsteğe bağlı --online ve --allow-build-network ek trafik açar: bkz. Ağ davranışı.
Ne kadar sürer?
İlk kurulum 5-15 dakika (bir Windows 11 makinesinde bir kez ölçüldü). --tools-only denetim dakikalar sürer. Ajanlı denetim profile ve repo boyutuna göre saatler sürebilir. Limit dolarsa kalkan bekler ve devam eder.
kalkan bilgisayarıma ne kurar?
Bir Python motoru, 22 sabit sürümlü araç (21 tarayıcı ve Go araç zinciri) ve yerel zafiyet veritabanları. Hepsi yaklaşık 5,5 GB tutar. kalkan sistem paketi kurmaz ve PATH'i değiştirmez. Ayrıntı: Dokümantasyon.
Nereye kurar?
Senin kullanıcı klasörüne: ~/.claude/plugins/data/kalkan-kalkan. Raporlar ~/kalkan-runs altına gider. Windows, macOS ve Linux yolları: Dokümantasyon.
kalkan'ı tamamen nasıl kaldırırım?
Saklamak istediğin raporları kopyala. claude plugin uninstall kalkan@kalkan ve claude plugin marketplace remove kalkan çalıştır. Sonra ~/kalkan-runs klasörünü sil. Bütün adımlar: Dokümantasyon.
Ücreti ne?
kalkan'ın kendi kodu MIT lisanslı ve ücretsiz. Paketle gelen Opengrep kural paketleri kendi lisanslarını korur: MIT, LGPL, GPL-3.0 ve AGPL-3.0. KALKAN_RULE_PACKS=osi AGPL paketini kapatır. Liste: Araçlar. Ajan adımları senin Claude planını veya API hesabını kullanır. --tools-only modu Claude Code gerektirmez.
Claude planı olmadan, API anahtarıyla çalışır mı?
Evet. Claude Code, Claude API, Microsoft Foundry, Amazon Bedrock ve Google Vertex ile çalışır. kalkan da onların üzerinden çalışır. Değişkenleri ayarla, kalkan doctor ile kontrol et ve harcamayı --max-usd ile sınırla. Rapor, her turun maliyetini ve hangi hesaptan ödendiğini yazar. Ayrıntı: Dokümantasyon.
Kodu düzeltir mi?
Hayır. kalkan denetlenen projeye hiç yazmaz. Her bulgu bir düzeltme önerisi taşır, SCA kayıtları düzeltilmiş sürümü söyler. Değişikliği sen yaparsın.
CI'da kullanabilir miyim?
Evet, --tools-only ile: tarayıcılar, SCA ve rapor Claude olmadan çalışır. findings.sarif GitHub code scanning için bir SARIF 2.1.0 dosyasıdır. Depodaki docker/ klasörü CI hatları için bir imaj tarifi tutar. Bu imaj desteklenen bir kurulum yolu değildir ve güncel araç seti için derlenmedi. Ayrıntı: Dokümantasyon.
Hangi dilleri ve dosyaları kapsar?
Dil paketleri: C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Solidity. Ayrıca C ve C++, Terraform, Kubernetes, Helm, Dockerfile, nginx, GitHub Actions, GitLab CI, Azure Pipelines, Tekton, OpenAPI.
Codex ile çalışır mı?
Evet. AGENTS.md ve $kalkan skill'i OpenAI Codex CLI içindir. Gözetimsiz çalışma --host codex ile başlar.
İki denetim aynı anda olur mu?
Evet. Her denetim kendi çalıştırma kimliğine bağlanır. Her birini ayrı bir terminalde başlat, yan denetime --no-latest ekle.
Bu site ziyaretçileri izliyor mu?
Site, ziyaretleri Azure Application Insights ile sayar: sayfa, ülke, tarayıcı ve nereden gelindiği. Çerez yazmaz, tarayıcıda veri saklamaz. Application Insights IP adresini tutmaz. Bu sayım yalnızca bu web sitesi için. Site ayrıca yazı tiplerini Google Fonts'tan yükler. Bu yüzden tarayıcın Google'a bir istek gönderir. kalkan aracı hiçbir veri göndermez.
Does my code leave the machine?
The scanners and SCA run offline. The agents run in your own Claude Code session, and Claude Code sends the files it reads to Anthropic or to your API provider. That is your own Claude traffic. kalkan adds nothing to it. A git URL target is cloned first. The opt-in --online and --allow-build-network add more traffic: see Network behavior.
How long does it take?
The first install takes 5 to 15 minutes (measured once on one Windows 11 machine). A --tools-only audit takes minutes. An audit with agents can take hours, by profile and repository size. When a limit stops it, kalkan waits and continues.
What does kalkan install on my computer?
A Python engine, 22 pinned tools (21 scanners and the Go toolchain) and local vulnerability databases. Together they use about 5.5 GB. kalkan installs no system package and does not change PATH. Details: Docs.
Where does it install it?
Into your user folder: ~/.claude/plugins/data/kalkan-kalkan. The reports go to ~/kalkan-runs. The paths on Windows, macOS and Linux: Docs.
How do I remove kalkan completely?
Copy the reports that you want to keep. Run claude plugin uninstall kalkan@kalkan and claude plugin marketplace remove kalkan. Then delete the folder ~/kalkan-runs. All steps: Docs.
What does it cost?
kalkan's own code is free under the MIT license. The bundled Opengrep rule packs keep their own licenses: MIT, LGPL, GPL-3.0 and AGPL-3.0. KALKAN_RULE_PACKS=osi turns the AGPL pack off. The list: Tools. The agent steps use your own Claude plan or API account. The --tools-only mode needs no Claude Code.
Does it work with an API key and no Claude plan?
Yes. Claude Code works with the Claude API, Microsoft Foundry, Amazon Bedrock and Google Vertex, and kalkan runs on top of them. Set the variables, check them with kalkan doctor, and cap the spend with --max-usd. The report shows the cost of every round and which account paid. Details: Docs.
Does it fix the code?
No. kalkan never writes to the audited project. Every finding carries a remediation, and SCA records name the fixed version. You make the change.
Can I use it in CI?
Yes, with --tools-only: the scanners, SCA and the report run without Claude. findings.sarif is a SARIF 2.1.0 file for GitHub code scanning. The docker/ folder of the repository holds an image recipe for CI pipelines. That image is not a supported install path, and it was not built for the current tool set. See the Docs.
Which languages and files?
Language packs: C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Solidity. Also C and C++, Terraform, Kubernetes, Helm, Dockerfile, nginx, GitHub Actions, GitLab CI, Azure Pipelines, Tekton, OpenAPI.
Does it work with Codex?
Yes. AGENTS.md and the $kalkan skill are for the OpenAI Codex CLI. Unattended runs start with --host codex.
Can two audits run at once?
Yes. Each audit binds to its own run ID. Start each one in its own terminal, and add --no-latest to the side audit.
Does this website track visitors?
The site counts visits with Azure Application Insights: the page, the country, the browser and the referrer. It sets no cookies and stores nothing in the browser. Application Insights does not keep the IP address. This count is for the website only. The site also loads its fonts from Google Fonts, so your browser sends a request to Google. The kalkan tool sends no data.
