KullanımUsage

Kur, denetle, devam et. Üç komut.Install, audit, resume. Three commands.

Kurulum araçları, Go'yu ve yerel zafiyet veritabanlarını kendisi indirir, sonra kalkan doctor ile her şeyi kontrol eder. Her hata kendi çözüm komutunu söyler.

The installer downloads the tools, Go and the local vulnerability databases itself, then checks everything with kalkan doctor. Each error names its own fix.

1

KurInstall

curl -fsSL https://raw.githubusercontent.com/dtechcloud/kalkan/stable/scripts/install.sh | sh
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/dtechcloud/kalkan/stable/scripts/install.ps1)))

İlk kurulum 5-15 dakika sürer. Aynı satır kalkan'ı günceller. Önce komutları görmek için | sh yerine | sh -s -- --dry-run yaz. PowerShell'de son parantezden sonra -DryRun ekle.

The first install takes 5 to 15 minutes. The same line updates kalkan. To see the commands first, write | sh -s -- --dry-run in place of | sh. In PowerShell, add -DryRun after the last parenthesis.

2

DenetleAudit

❯ kalkan-audit https://github.com/org/shop
# Claude Code
/kalkan C:/code/shop deep

Bir klasör veya git URL'si ver. Terminalde, Claude Code oturumunda veya VS Code eklentisinde aynı denetim çalışır. Raporlar ~/kalkan-runs/ altına gider.

Give a folder or a git URL. The same audit runs in a terminal, in a Claude Code session or in the VS Code extension. The reports go to ~/kalkan-runs/.

3

Devam etResume

❯ kalkan-audit devam 20261026T091512Z-shop-3f2a
# Claude Code
/kalkan devam

Durma mesajı çalıştırma kimliğini söyler. devam tek başına en yeni denetimi sürdürür. Terminaldeki denetim limit sıfırlanmasını zaten kendisi bekler.

The stop message names the run ID. devam alone resumes the newest audit. An audit in the terminal already waits through usage-limit resets by itself.
