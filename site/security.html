Güvenlik modeliSecurity model

Üç söz. Her biri bir testle korunur.Three promises. A test holds each one.

Bir güvenlik aracı, denetlediği kod kadar kendine de dikkat etmeli. kalkan'ın sözleri ve nasıl uygulandıkları docs/SECURITY.md içinde, kalan riskleriyle birlikte yazılı.

A security tool must be as careful with itself as with the code it audits. kalkan's promises and how it keeps them are in docs/SECURITY.md, together with the residual risks.

01

Denetlenen proje değişmez.The audited project never changes.

Denetim bir kopya üzerinde çalışır. kalkan hedefte hiçbir dosyayı ve klasörü değiştirmez. Bir tuzak repo testi her dosyayı, klasörü ve değişiklik zamanını kontrol eder.

The audit works on a copy. kalkan changes no file and no folder of the target. A trap repository test checks every file, folder and modification time.

02

Ajanlar yalnız kendi dosyasına yazar.Agents write only their own file.

Alt ajanların yalnız Read, Grep, Glob ve Write araçları var. Kabuk yok, web yok, MCP aracı yok. Her ajan tek bir dosya yazar: kendi sonucunu.

The subagents have only Read, Grep, Glob and Write. No shell, no web, no MCP tools. Each agent writes exactly one file: its own result.

03

Veri makinede kalır.Data stays on the machine.

Tarayıcılar ve SCA varsayılan olarak ağsız çalışır. Dışarı çıkan tek trafik, senin Claude oturumunun Anthropic'e trafiği. Proxy tuzağı testinde gerçek araçlar sıfır bağlantı açtı.

The scanners and SCA run without network by default. The only traffic that leaves is your own Claude session to Anthropic. In the proxy trap test, the real tools opened zero connections.

  • Hedefin CLAUDE.md, AGENTS.md, .claude/, .cursorrules gibi talimat dosyaları .kalkan-neutralized adıyla etkisiz kalır.Instruction files of the target (CLAUDE.md, AGENTS.md, .claude/, .cursorrules and others) get the suffix .kalkan-neutralized.
  • Her ajan istemi hedefin talimat değil veri olduğunu söyler. Canlı testte hedefteki saldırgan yorumu ajan rapor etti, uygulamadı.Every agent prompt says that the target is data, not instructions. In a live test, the agent reported a hostile comment in the target and did not obey it.
  • Tarayıcılar hedef kodu asla çalıştırmaz. Docker varsa PoC sandbox hedef kodu yalnız kopyadan, ağsız bir konteynerde çalıştırır.The scanners never run target code. With Docker, the PoC sandbox runs target code only from the copy, in a container without network.
  • Kingfisher bulduğu bir sırrı sağlayıcısında asla denemez. Hiçbir sır değeri bir kalkan dosyasına yazılmaz.Kingfisher never tries a found secret at its provider. No secret value reaches a kalkan file.
