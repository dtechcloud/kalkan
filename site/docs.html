01

BaşlangıçGetting started

kalkan, kaynak kodunu güvenlik açısından denetler. Sabit sürümlü tarayıcılar ve Claude Code ajanları şüphelileri bulur. Ajanlar önemli şüphelileri kaynak kodda doğrular. Motor her kararı hesaplar ve raporu yazar.

kalkan audits the security of your source code. Pinned scanners and Claude Code agents find the candidates. The agents verify the important candidates in the source code. The engine computes each verdict and writes the report.

  1. 01Gereksinimleri kontrol et: Python, git ve Claude Code.Check the requirements: Python, git and Claude Code.
  2. 02Kurulum satırını çalıştır.Run the install line.
  3. 03İlk denetimi başlat: Claude Code'da /kalkan veya terminalde kalkan-audit.Start the first audit: /kalkan in Claude Code, or kalkan-audit in a terminal.
  4. 04Raporu aç. Önce EXECUTIVE.html dosyasını oku.Open the report. Read EXECUTIVE.html first.

Bir adım çalışmazsa Sorun giderme bölümüne bak.

If a step fails, see Troubleshooting.

Sık sorulan üç soruThree common questions

  • Bilgisayarıma ne kurar?What does kalkan install on my computer?Bir Python motoru, 22 sabit sürümlü araç (21 tarayıcı ve Go araç zinciri) ve yerel zafiyet veritabanları. Hepsi yaklaşık 5,5 GB tutar. kalkan sistem paketi kurmaz. Ayrıntı: Bilgisayarıma ne kurar?A Python engine, 22 pinned tools (21 scanners and the Go toolchain) and local vulnerability databases. Together they use about 5.5 GB. kalkan installs no system package. Details: What does kalkan install?
  • Nereye kurar?Where does it install it?Senin kullanıcı klasörüne: ~/.claude/plugins/data/kalkan-kalkan. Raporlar ~/kalkan-runs altına gider. Windows'ta ~, C:\Users\<user> klasörüdür. Ayrıntı: Nereye kurar?Into your user folder: ~/.claude/plugins/data/kalkan-kalkan. The reports go to ~/kalkan-runs. On Windows, ~ is the folder C:\Users\<user>. Details: Where does it install it?
  • Tamamen nasıl kaldırırım?How do I remove it completely?Saklamak istediğin raporları kopyala. Plugin'i ve marketplace'i kaldır. Sonra ~/kalkan-runs klasörünü sil. Bütün adımlar: Tam temizlikCopy the reports that you want to keep. Remove the plugin and the marketplace. Then delete the folder ~/kalkan-runs. All steps: Full cleanup

02

GereksinimlerRequirements

kalkan Windows 11, Linux ve macOS'ta çalışır. Bütün araç setini Windows 11'de ve Ubuntu 24.04'te test ettik (Ubuntu: 2026-11-11'de bir konteynerde bir kez). macOS'ta CI birim testlerini çalıştırır. Kurulumdan önce bu listeyi kontrol et.

kalkan runs on Windows 11, Linux and macOS. The full tool set is tested on Windows 11 and on Ubuntu 24.04 (one run in a container on 2026-11-11). macOS runs the unit tests in CI. Check this list before the install.

  • Python 3.11+Kurulum, motorun venv'ini bu Python ile oluşturur. py -3, python3 veya python PATH'te olmalı.The setup creates the venv of the engine with this Python. py -3, python3 or python must be on PATH.
  • gitWindows'ta Git for Windows gerekir. Plugin, motoru Git Bash üzerinden çalıştırır.On Windows, you need Git for Windows. The plugin runs the engine through Git Bash.
  • Claude Code 2.1+CLI veya VS Code eklentisi, oturumu açık. Ajan adımları senin Claude planını kullanır. Plan yerine bir API anahtarı da olur: API anahtarıyla çalıştırma. --tools-only denetimi Claude Code istemez. --max-usd için Claude Code 2.1.217 veya üstü gerekir.The CLI or the VS Code extension, signed in. The agent steps use your own Claude plan. An API key works in place of a plan: Running with an API key. A --tools-only audit needs no Claude Code. --max-usd needs Claude Code 2.1.217 or later.
  • İnternetNetworkKurulum ve güncelleme, araçları ve zafiyet veritabanlarını indirir. Denetim, Claude oturumun dışında ağ kullanmaz. Bir git URL'si hedefi klon için ağ ister. --allow-build-network (isteğe bağlı, varsayılan kapalı) PoC sandbox'ının imajları ağ erişimiyle çekmesine ve derlemesine izin verir. Ayrıntı: Ağ davranışıThe setup and the updates download the tools and the vulnerability databases. An audit uses no network except your Claude session. A git URL target needs the network for the clone. --allow-build-network (opt-in, off by default) lets the PoC sandbox pull and build images with network access. Details: Network behavior
  • Diskkalkan bütün parçalarıyla yaklaşık 5,5 GB tutar. Kurulum sırasında Go derleme klasörü (0,76 GB) ve indirilen arşivler kısa bir süre daha fazla yer ister. Denetimler ayrıca yer tutar. Ayrıntı: Disk kullanımıkalkan uses about 5.5 GB with all its parts. During the setup, the Go build folder (0.76 GB) and the downloaded archives need more space for a short time. The audits need more space too. Details: Disk usage
  • Docker, isteğe bağlıDocker, optionalDocker Desktop veya Docker Engine. Yalnız PoC sandbox adımı kullanır.Docker Desktop or Docker Engine. Only the PoC sandbox step uses it.
  • Yönetici hakkıAdministrator rightsGerekmez. kalkan her şeyi kendi kullanıcı klasörüne kurar.Not needed. kalkan installs everything in your user folder.

03

KurulumInstallation

Önerilen yol, tek satırlık kurulum betiğidir. Terminaline uyan satırı çalıştır.

The one-line installer is the recommended way. Run the line for your terminal.

curl -fsSL https://raw.githubusercontent.com/dtechcloud/kalkan/stable/scripts/install.sh | sh
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/dtechcloud/kalkan/stable/scripts/install.ps1)))

Betik ne yapar?What the installer does

  1. 01git'i, Python'u ve Claude Code oturumunu kontrol eder. git'in repoyu okuyabildiğini de kontrol eder.It checks git, Python and the Claude Code login, and that git can read the repository.
  2. 02kalkan marketplace'ini Claude Code'a ekler.It adds the kalkan marketplace to Claude Code.
  3. 03Plugin'i kendi kullanıcın için kurar (user scope).It installs the plugin for your user (user scope).
  4. 04Motoru, sabit sürümlü tarayıcıları ve zafiyet veritabanlarını kurar. Sonra kalkan doctor çalıştırır.It installs the engine, the pinned scanners and the vulnerability databases. Then it runs kalkan doctor.
  5. 05Denetim komutunu senin yollarınla yazar.It prints the audit command with your paths.

Her hata mesajı kendi düzeltme komutunu verir. Komutları önce görmek için | sh yerine | sh -s -- --dry-run yaz. PowerShell'de son parantezden sonra -DryRun ekle.

Each error message names its own fix. To see the commands first, write | sh -s -- --dry-run in place of | sh. In PowerShell, add -DryRun after the last parenthesis.

--skip-setup (PowerShell'de -SkipSetup) motorun kurulumunu sonraki /kalkan komutuna bırakır. Tek satır yerine repoyu da klonlayabilirsin: önce git clone https://github.com/dtechcloud/kalkan.git, sonra sh kalkan/scripts/install.sh çalıştır. Windows'ta ikinci komut powershell -ExecutionPolicy Bypass -File kalkan\scripts\install.ps1 olur.

--skip-setup (-SkipSetup in PowerShell) leaves the setup of the engine to the next /kalkan. You can also clone the repository in place of the one-liner: run git clone https://github.com/dtechcloud/kalkan.git, then sh kalkan/scripts/install.sh. On Windows, the second command is powershell -ExecutionPolicy Bypass -File kalkan\scripts\install.ps1.

Kurulumun neyi nereye yazdığı: Bilgisayarıma ne kurar?

What the setup writes, and where: What does kalkan install?

SüreTime

İlk kurulum çoğu zaman 5-15 dakika sürer. Süre en çok ağın hızına bağlıdır. 29 Ekim 2026'da hızlı bir ağda kurulum yaklaşık 3 dakika sürdü. Yavaş bir ağda bir kurulum 56 dakika sürdü. Bu sürenin 46 dakikası zafiyet veritabanlarının indirmesiydi. Sonraki /kalkan başlangıçları yaklaşık 2 saniye sürer. Bu süreler bir Windows 11 makinesinde bir kez ölçüldü.

The first setup usually takes 5 to 15 minutes. The time depends mostly on the speed of the network. On 29 October 2026, a setup on a fast network took about 3 minutes. On a slow network, one setup took 56 minutes. The download of the vulnerability databases used 46 of these minutes. Later /kalkan starts take about 2 seconds. These times were measured once on one Windows 11 machine.

GüncellemeUpdate

kalkan'ı güncellemek için aynı satırı yeniden çalıştır. Bir denetim çalışırken asla güncelleme yapma. Ayrıntılar: Güncelleme.

To update kalkan, run the same line again. Never update while an audit runs. Details: Updating.

Elle kurulumManual install

Betik yerine Claude Code CLI'ı da kullanabilirsin. Claude Code, marketplace'i git ile klonlar. #stable denenmiş sürümleri izler. En yeni değişiklikler için #main yaz.

You can also use the Claude Code CLI in place of the installer. Claude Code clones the marketplace with git. #stable follows the tested releases. For the newest changes, write #main.

claude plugin marketplace add dtechcloud/kalkan#stable
claude plugin install kalkan@kalkan --scope user

Sonra Claude Code'u yeniden başlat. İlk /kalkan motoru, tarayıcıları ve veritabanlarını kendisi kurar.

Then restart Claude Code. The first /kalkan installs the engine, the scanners and the databases itself.

VS Code eklentisinde çalışma alanı güvenilir (trusted) olmalı. /plugins yaz. Marketplaces sekmesinde dtechcloud/kalkan#stable ekle. Plugins sekmesinden kalkan'ı kur.

In the VS Code extension, the workspace must be trusted. Type /plugins. Add dtechcloud/kalkan#stable on the Marketplaces tab. Install kalkan from the Plugins tab.

04

İlk denetimFirst audit

Bir yerel klasör veya bir git URL'si seç. kalkan hedefin bir kopyasında çalışır. Hedefte hiçbir dosyayı değiştirmez.

Choose a local folder or a git URL. kalkan works on a copy of the target. It changes no file of the target.

Claude Code'daIn Claude Code

  1. 01Claude Code'u herhangi bir klasörde aç.Open Claude Code in any folder.
  2. 02

    /kalkan yaz. Arkasına hedefi ve profili ekle.

    Type /kalkan. Add the target and the profile after it.

    /kalkan C:/code/shop standard
  3. 03Başlangıç mesajındaki çalıştırma kimliğini (run ID) not al.Note the run ID from the start message.
  4. 04Denetim bitince son mesajdaki rapor yolunu aç.When the audit is done, open the report path from the last message.

İlk /kalkan kurulumu tamamlar ve bunu sana söyler. Motor güncelse denetim hemen başlar. Rapor varsayılan olarak İngilizce. Türkçe rapor için komuta --lang tr ekle. Türkçe bir denetimin sonunda kalkan İngilizce sürümü de sorar.

The first /kalkan completes the setup and tells you so. When the engine is current, the audit starts at once. The report is English by default. For a Turkish report, add --lang tr to the command. At the end of a Turkish run, kalkan offers the English version too.

Kullanım limiti denetimi durdurursa sıfırlanmayı bekle. Sonra /kalkan devam <run-id> yaz. Hiçbir görev kaybolmaz.

If a usage limit stops the audit, wait for the reset. Then type /kalkan devam <run-id>. No task is lost.

TerminaldeIn a terminal

kalkan-audit denetimi sohbet olmadan çalıştırır. Kullanım limitlerini kendisi bekler. Uzun bir denetim için bu yolu seç. Komutu tam yoluyla çalıştır:

kalkan-audit runs the audit without a chat. It waits through usage limits by itself. Use this way for a long audit. Run the command with its full path:

sh ~/.claude/plugins/data/kalkan-kalkan/bin/kalkan-audit https://github.com/org/shop --open
& "$HOME\.claude\plugins\data\kalkan-kalkan\bin\kalkan-audit.cmd" https://github.com/org/shop --open

Komut önce kurulumu kontrol eder. Eksik bir aracı veya veritabanını yalnız --yes ile ya da sen y dersen kurar. Sonra tarayıcıları, SCA'yı ve ajan turlarını çalıştırır. --open sonda yönetici özetini tarayıcıda açar.

The command first checks the setup. It installs a missing tool or database only with --yes, or after you answer y. Then it runs the scanners, SCA and the agent rounds. --open opens the executive summary in the browser at the end.

Sondaki özet genel riski, ciddiyete göre doğrulanan bulguları, en önemli 3 bulguyu ve rapor dosyalarını gösterir. Kararların anlamı: Ajan doğrulaması.

The summary at the end shows the overall risk, the confirmed findings by severity, the top 3 findings and the report files. The meaning of the verdicts: AI verification.

Önce hızlı bir bakışA quick look first

Ajanlar olmadan yalnız tarayıcıları ve SCA'yı çalıştırmak için --tools-only ekle. Bu denetim Claude Code istemez ve Claude planını kullanmaz. Sonuçları doğrulanmamış araç sonuçlarıdır.

To run only the scanners and SCA without agents, add --tools-only. This audit needs no Claude Code and does not use your Claude plan. Its results are unverified tool results.

SüreTime

Süre profile ve kodun boyutuna bağlıdır. Ölçülmüş örnekler: Ölçümler.

The time depends on the profile and on the size of the code. Measured examples: Benchmarks.

05

Denetim profilleriAudit profiles

Profil, denetimin derinliğini seçer. Varsayılan profil standard profilidir.

A profile sets the depth of an audit. The default profile is standard.

  • fastİlk bakış ve küçük repolar için. En çok 40 ajan görevi ve 1 eleştirmen dalgası. Ayrı bir son inceleme yok. Diğer kabul edilen adlar: hizli, hızlı, quick.For a first look and small repositories. At most 40 agent tasks and 1 critic wave. No separate final review. Also accepted: hizli, hızlı, quick.
  • standardVarsayılan. En çok 150 ajan görevi ve 2 eleştirmen dalgası. Son inceleme var. Diğer kabul edilen ad: standart.The default. At most 150 agent tasks and 2 critic waves. With a final review. Also accepted: standart.
  • deepBüyük veya kritik sistemler için. En çok 400 ajan görevi ve 3 eleştirmen dalgası. Son inceleme var. Diğer kabul edilen ad: derin.For large or critical systems. At most 400 agent tasks and 3 critic waves. With a final review. Also accepted: derin.

Ajan görevi bütçesi, bir denetimin en çok kaç alt ajan görevi çalıştıracağını sınırlar. Her görev senin Claude planını kullanır. Eleştirmen dalgası sayısı, av dalgası sayısıyla aynıdır.

The agent task budget limits the number of subagent tasks in an audit. Each task uses your Claude plan. The number of critic waves is also the number of hunt waves.

fast profilinin raporu her zaman bir kısmi geçiş (partial pass) notu taşır. Bütçe biterse rapor kalan boşlukları listeler. Daha büyük bir profille yeni bir denetim bu boşlukları kapatabilir.

A report of the fast profile always carries a partial pass note. When the budget runs out, the report lists the remaining gaps. A new audit with a larger profile can close them.

Profili seçChoose a profile

# Claude Code
/kalkan C:/code/shop deep
# Terminal
kalkan-audit C:/code/shop --profile deep

Diğer adlar (hizli, quick, standart, derin) de çalışır. devam bir denetimi kendi profiliyle sürdürür. --tools-only ile profilin bir etkisi yoktur, çünkü hiçbir ajan çalışmaz.

The other names (hizli, quick, standart, derin) work too. devam resumes an audit with its own profile. With --tools-only, the profile has no effect, because no agent runs.

06

Komutlar ve yollarCommands and paths

Denetimi iki yoldan başlatırsın: Claude Code içinde /kalkan ile veya terminalde kalkan-audit ile. Kısa bir özet Kullanım sayfasında.

You start an audit in one of two ways: with /kalkan in Claude Code, or with kalkan-audit in a terminal. The Usage page has a short summary.

  • /kalkanClaude Code içinde denetim, örneğin /kalkan C:/code/shop deep. Bir klasör veya git URL'si ver.An audit in Claude Code, for example /kalkan C:/code/shop deep. Give a folder or a git URL.
  • fast · standard · deepProfiller: ilk bakış, varsayılan, büyük veya kritik sistemler. Ayrıntı: Denetim profilleri.Profiles: a first look, the default, large or critical systems. Details: Audit profiles.
  • devamMola veya kullanım limitinden sonra devam: /kalkan devam <run-id> ya da terminalde kalkan-audit devam <run-id>. Tek başına devam en yeni denetimi sürdürür.Resume after a break or a usage limit: /kalkan devam <run-id>, or kalkan-audit devam <run-id> in a terminal. devam alone resumes the newest audit.
  • --no-latestParalel denetim: her denetimi kendi oturumunda veya terminalinde başlat. Yan denetime --no-latest ekle.Parallel audits: start each audit in its own session or terminal. Add --no-latest to the side audit.
  • --live <path>Canlıda çalışan kurulumun klasörü, örneğin --live deploy/helm. Bir repoda compose, Helm ve Kubernetes birlikte olabilir. Yalnızca canlıda kullanılmayan bir kurulum dosyasındaki bulgu "yalnızca şablon" olarak işaretlenir ve genel riske katılmaz. Denetimden sonra da verebilirsin: kalkan run set --live <yol>, sonra kalkan report.The folder of the deployment that runs in production, for example --live deploy/helm. A repository can hold compose, Helm and Kubernetes at once. A finding only in a deployment file that does not run in production is marked "template only" and left out of the overall risk. You can also give it after the audit: kalkan run set --live <path>, then kalkan report.
  • --not-live <path>Canlıda yüklenmeyen kodun klasörü, örneğin yalnız başka bir ürünün yüklediği bir eklenti klasörü. Bir bulgunun bütün sink adımları bu klasördeyse bulgu "yalnızca şablon" olarak işaretlenir. --live ile çakışırsa --live kazanır. Denetimden sonra: kalkan run set --not-live <yol>, sonra kalkan report.The folder of code that production does not load, for example a plugin folder that only another product loads. When every sink step of a finding is in this folder, the finding is marked "template only". When it overlaps --live, --live wins. After the audit: kalkan run set --not-live <path>, then kalkan report.
  • kalkan run compare <A> <B>İki veya daha fazla denetimi karşılaştırır: her denetimin bulduğu ve yalnız bazılarının bulduğu açıklar, değişen kararlar ve ciddiyetler, her denetimin tipi, süresi ve maliyeti. Aynı commit'in tekrar denetimleri için kararlılık oranını verir.Compares two or more audits: the issues that every audit found and the ones that only some found, the changed verdicts and severities, and the type, time and cost of each audit. For repeated audits of the same commit it gives the stability rate.
  • kalkan-auditGözetimsiz denetim: terminalde sohbet olmadan çalışır ve kullanım limitlerini bekler. --max-hours N süreyi sınırlar (varsayılan 24).Unattended audit: it runs in a terminal without a chat and waits through usage limits. --max-hours N limits the time (default 24).
  • --max-usd NDenetimin kayıtlı maliyeti N dolara ulaşınca yeni tur başlamaz. API anahtarıyla çalışırken kullan: API anahtarıyla çalıştırma. Claude Code 2.1.217 veya üstü gerekir.No new round starts when the recorded cost of the audit reaches N dollars. Use it with an API key: Running with an API key. It needs Claude Code 2.1.217 or later.
  • --tools-onlyYalnız tarayıcılar, SCA ve rapor, Claude Code olmadan. Sonuçlar doğrulanmamış araç sonuçlarıdır.Only the scanners, SCA and the report, without Claude Code. The results are unverified tool results.
  • --openDenetim sonunda EXECUTIVE.html dosyasını varsayılan tarayıcıda açar.Opens EXECUTIVE.html in the default browser at the end of the audit.
  • --yesEksik araçları ve veritabanlarını sormadan kurar. Bu indirme ağı kullanır.Installs missing tools and databases without a question. This download uses the network.

Terminalde tam yolThe full path in a terminal

kalkan PATH'i değiştirmez. Bu yüzden kalkan-audit komutunu tam yoluyla çalıştır. Kurulum betiği bu komutu senin yollarınla yazar.

kalkan does not change PATH. Thus, run kalkan-audit with its full path. The installer prints this command with your paths.

sh ~/.claude/plugins/data/kalkan-kalkan/bin/kalkan-audit https://github.com/org/shop --profile deep
& "$HOME\.claude\plugins\data\kalkan-kalkan\bin\kalkan-audit.cmd" https://github.com/org/shop --profile deep

Motor komutları da PATH'te değil. Bu belgelerde kalkan, motorun tam yolu demektir. Kurulumun son satırı (engine: <yol>) bu yolu verir. Örnek: kalkan doctor.

The engine commands are not on PATH either. In these docs, kalkan means the full path of the engine. The last line of the setup (engine: <path>) names this path. Example: kalkan doctor.

# Linux, macOS
~/.claude/plugins/data/kalkan-kalkan/venv/bin/kalkan doctor
# Git Bash (Windows)
~/.claude/plugins/data/kalkan-kalkan/venv/Scripts/kalkan.exe doctor
# PowerShell
& "$HOME\.claude\plugins\data\kalkan-kalkan\venv\Scripts\kalkan.exe" doctor

API anahtarıyla çalıştırmaRunning with an API key

Ajan adımları Claude Code içinde çalışır. Claude Code bir Claude planıyla veya bir API hesabıyla çalışabilir. kalkan ikisini de kullanır ve ayrı bir ayar istemez. Ortamda bir API değişkeni varsa Claude Code onu kullanır. Bu durumda her tur API hesabına faturalanır.

The agent steps run in Claude Code. Claude Code works with a Claude plan or with an API account. kalkan uses both and needs no own setting. When the environment holds an API variable, Claude Code uses it, and the API account pays for every round.

  • Claude APIANTHROPIC_API_KEY
  • Microsoft FoundryCLAUDE_CODE_USE_FOUNDRY=1, ANTHROPIC_FOUNDRY_RESOURCE (veya(or ANTHROPIC_FOUNDRY_BASE_URL), ANTHROPIC_FOUNDRY_API_KEY (yoksa Entra ID: az login)(without it, Entra ID: az login)
  • Amazon BedrockCLAUDE_CODE_USE_BEDROCK=1, AWS_REGION ve AWS kimlik bilgileriand AWS credentials
  • Google VertexCLAUDE_CODE_USE_VERTEX=1, CLOUD_ML_REGION, ANTHROPIC_VERTEX_PROJECT_ID

Foundry, Bedrock ve Vertex'te model adlarını ver: ANTHROPIC_DEFAULT_OPUS_MODEL, ANTHROPIC_DEFAULT_SONNET_MODEL ve ANTHROPIC_DEFAULT_HAIKU_MODEL. Foundry'de bu değerler deployment adlarındır. Örnek, Microsoft Foundry ile bir fast denetim:

On Foundry, Bedrock and Vertex, set the model names: ANTHROPIC_DEFAULT_OPUS_MODEL, ANTHROPIC_DEFAULT_SONNET_MODEL and ANTHROPIC_DEFAULT_HAIKU_MODEL. On Foundry, these values are deployment names. Example, a fast audit with Microsoft Foundry:

export CLAUDE_CODE_USE_FOUNDRY=1
export ANTHROPIC_FOUNDRY_RESOURCE=<resource-name>
export ANTHROPIC_FOUNDRY_API_KEY=<key>
export ANTHROPIC_DEFAULT_OPUS_MODEL=<opus-deployment>
export ANTHROPIC_DEFAULT_SONNET_MODEL=<sonnet-deployment>
export ANTHROPIC_DEFAULT_HAIKU_MODEL=<haiku-deployment>
~/.claude/plugins/data/kalkan-kalkan/venv/bin/kalkan doctor
sh ~/.claude/plugins/data/kalkan-kalkan/bin/kalkan-audit C:/code/shop --profile fast --max-usd 100
$env:CLAUDE_CODE_USE_FOUNDRY = "1"
$env:ANTHROPIC_FOUNDRY_RESOURCE = "<resource-name>"
$env:ANTHROPIC_FOUNDRY_API_KEY = "<key>"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL = "<opus-deployment>"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL = "<sonnet-deployment>"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL = "<haiku-deployment>"
& "$HOME\.claude\plugins\data\kalkan-kalkan\venv\Scripts\kalkan.exe" doctor
& "$HOME\.claude\plugins\data\kalkan-kalkan\bin\kalkan-audit.cmd" C:\code\shop --profile fast --max-usd 100
  1. 01kalkan doctor çıktısında claude satırı API: foundry der. Eksik bir değişken varsa satır onun adını verir.In the kalkan doctor output, the claude row says API: foundry. When a variable is missing, the row names it.
  2. 02--max-usd N harcamayı sınırlar. Kayıtlı maliyet N dolara ulaşınca kalkan yeni tur başlatmaz. Her tur, kalan tutarı --max-budget-usd olarak alır. Daha fazla harcamak için devam <run-id> --max-usd <yeni sınır> çalıştır.--max-usd N caps the spend. When the recorded cost reaches N dollars, kalkan starts no new round. Each round gets the rest as --max-budget-usd. To spend more, run devam <run-id> --max-usd <new cap>.
  3. 03Rapor maliyeti "API hesabından ödendi (foundry)" diye yazar. Tutar, Claude Code'un liste fiyatıyla yaptığı tahmindir. Kesin tutar sağlayıcının faturasındadır. Çalıştırma klasöründeki usage.jsonl her turun giriş yöntemini, modelini, maliyetini ve token sayısını tutar.The report shows the cost as "billed to an API account (foundry)". The amount is the estimate of Claude Code at list prices. The bill of the provider is the authority. usage.jsonl in the run folder holds the login mode, the model, the cost and the tokens of every round.

Hesabının hız limiti düşükse paralel ajan sayısını düşür: kalkan run set --max-parallel 2. Claude Code 429 ve 529 hatalarında kendisi yeniden dener. Gözetimsiz bir denetimde CLAUDE_CODE_RETRY_WATCHDOG=1 bu denemeleri sınırsız yapar.

When the rate limit of your account is low, lower the parallel agents: kalkan run set --max-parallel 2. Claude Code retries 429 and 529 errors itself. In an unattended audit, CLAUDE_CODE_RETRY_WATCHDOG=1 retries them without a limit.

Anahtarı ortam değişkeninde veya bir sır yöneticisinde tut, hiçbir repoya yazma. kalkan anahtarın yalnızca değişken adını kaydeder, değerini hiçbir dosyaya yazmaz. Bir API oturumunda /kalkan ile yapılan etkileşimli denetim de API hesabını kullanır, ama maliyeti yalnızca kalkan-audit kaydeder.

Keep the key in an environment variable or a secret manager, never in a repository. kalkan records only the name of the variable and never writes its value to a file. An interactive /kalkan audit in an API session also uses the API account, but only kalkan-audit records the cost.
