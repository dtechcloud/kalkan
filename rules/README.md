# rules

- `matchers/`: regex matcher specs, a port of the deepsec matchers (phase 2), plus kalkan's own rules (`source: null`, notes "kalkan rule (ADR-0005, ...)"; `scripts/port_deepsec_matchers.py` never writes them).
- `opengrep/`: kalkan's own Opengrep rule pack (phase 2).
- `opengrep-packs/`: curated third-party Opengrep rule packs (GitLab sast-rules, Trail of Bits, 0xdea; ADR-0005 K.8; and Atlassian, elttam, njsscan, mobsfscan, mindedsecurity, Aikido and semgrep-codeql; ADR-0007). `curation.json` is written by hand; `index.json` and the `rules.yaml` bundles are generated by `scripts/build_opengrep_packs.py` from `third_party/`. Each bundle keeps the license of its pack (THIRD_PARTY.md).

kalkan does not ship Semgrep registry rules, because their license forbids redistribution.
